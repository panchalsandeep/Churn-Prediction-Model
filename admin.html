Admin Console

Sign in with the admin credentials configured on the server.

The admin password is the ADMIN_PASSWORD variable on the server. To reset it, open your hosting dashboard (Railway: project → service → Variables), change ADMIN_PASSWORD and redeploy. Changing ADMIN_TOKEN_SECRET also signs out every open admin session.
