🔑 How to reset your Admin password

The Admin password for this login page is stored as an environment variable on Vercel. To reset it:

1. Go to your Vercel Dashboard
2. Open churn-prediction-model → Settings → Environment Variables
3. Edit ADMIN_PASSWORD and set your new password
4. Redeploy the project for the change to take effect
